Recognition logic

Prototype classifier

MoveSense smooths accelerometer magnitude and evaluates recent signal variation. Repeated movement peaks are used as an approximate step signal. Activity labels are estimated using movement intensity and cadence. This is a transparent rule-based baseline, not a clinically validated or trained machine-learning model.
